Eine Sammlung von 26 nützlichen PowerShell-Funktionen für den täglichen Gebrauch.

## 📦 Installation

```powershell
# Profil-Datei öffnen
notepad $PROFILE

# Code aus Microsoft.PowerShell_profile.ps1 einfügen und speichern

# Profil neu laden
. $PROFILE

# Hilfe Funktion
hilfe - zeigt alle Funktionen an

# Funktionen A-Z
Befehl	Beschreibung
a	Zeigt Akkustatus und Restlaufzeit an
b	Öffnet Browser 
c	Taschenrechner - Rechnung berechnen oder GUI öffnen
d	Zeigt aktuelles Datum an und öffnet Kalendar
e	Schere-Stein-Papier Best-of-5 gegen PC
f	Leert den Papierkorb (mit Sicherheitsabfrage)
g	Öffnet GitHub im Browser
h	Ruft Wikipedia Artikel auf
i	Startet bunten Bildschirm-Reiniger (Strg+C zum Beenden)
j	Gibt Text in Regenbogenfarben aus
k	Münzwurf - Kopf oder Zahl
l	Zeigt Ordner-Größe in MB und GB an
m	Erstellt sichere Passwörter
n	Berechnet Notenpunkte aus erreichten Punkten
o	Wechselt zum Projekt-Ordner
p	Scannt Netzwerk nach aktiven Geräten
q	Zeigt Geo-Informationen zu IP-Adresse
r	Wechselt zum Home Verzeichnis
s	Zeigt das Wetter an
t	Speedtest - Ping, Download, Upload
u	Sucht nach Windows-Updates
v	Spielt Blackjack gegen den PC
w	Würfeln (1-6)
x	Öffnet Office-Programme (Word, Excel, etc.)
y	Konvertiert Text zu Morse-Code und zurück
z	Zahlenraten-Spiel (1-100)
